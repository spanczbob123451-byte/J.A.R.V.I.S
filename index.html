Klucz AI (Groq)

Aby AURA odpowiadała na wszystko jak ChatGPT, wklej darmowy klucz API z Groq.

1. Wejdź na console.groq.com/keys
2. Zaloguj się (Google/GitHub)
3. Kliknij Create API Key
4. Skopiuj klucz i wklej powyżej

Klucz jest zapisywany tylko lokalnie w przeglądarce.
